# SymbolBox · 여기 있어 특수문자

> 복사 한 번으로 끝내는 특수문자 모음집 — **문서·PDF에서 깨지지 않는 문자**까지 알려 줍니다.

**v2.0 · All New SymbolBox** — <https://symbolbox.chichiboo.link>

단일 HTML 파일 특수문자 모음 웹앱입니다. 설치 없이 브라우저에서 바로 열어 쓸 수 있고,
클릭 한 번으로 클립보드에 복사됩니다. 3,136종의 문자를 18개 분류로 정리했습니다.

---

## v2.0에서 새로 생긴 것

### 1. 문서·PDF 호환성 진단 (핵심)

한글(HWP)·워드에서 잘 보이던 기호가 PDF로 저장하면 네모(□)로 깨지거나 사라지는 일이 있습니다.
SymbolBox는 문자마다 **호환 등급**을 자동으로 매겨 미리 알려 줍니다.

| 등급 | 뜻 | 판정 기준 |
|---|---|---|
| 🟢 **안전** | 한글·워드 기본 글꼴(바탕·굴림·맑은 고딕·함초롬)에 모두 있음. PDF·인쇄까지 안전 | KS X 1001 특수문자 영역 + 한글 문서 글꼴 공통 지원 구간 |
| 🟡 **보통** | 요즘 글꼴에선 대개 보이지만 문서 글꼴에 따라 빈칸이 될 수 있음 | 유니코드 기본 다국어 평면(BMP) |
| 🔴 **주의** | 컬러 이모지·확장 영역 문자. PDF 변환·인쇄에서 깨질 가능성이 높음 | SMP(플레인 1) · 컬러 이모지 기본 표시 · 변형 선택자(U+FE0F) · ZWJ 조합 |

현재 데이터 기준 분포는 **안전 1,033 · 보통 1,087 · 주의 1,016**입니다.

- **카드 등급 색점** — 카드 왼쪽 위 점만 봐도 안전한 문자인지 알 수 있어요.
- **PDF 안전 모드** — 스위치 하나로 깨질 수 있는 문자를 목록에서 숨깁니다.
- **안전한 대체 문자 제안** — `⭐→★` `✅→✔` `❤️→♥` `➡️→→` `⬛→■` `🔴→●` `⚠️→※` `👉→☞` 처럼
  뜻이 같으면서 안전한 문자를 함께 알려 주고, 그 자리에서 복사할 수 있습니다.

### 2. 문서 호환성 검사기

작성한 글을 통째로 붙여넣으면 **깨질 문자를 찾아 표시하고, 한 번에 안전한 문자로 바꿔 줍니다.**

```
⭐ 중요 안건 ✅ 완료 ➡️ 다음 단계 ※ 참고
        ↓  안전 문자로 변환
★ 중요 안건 ✔ 완료 → 다음 단계 ※ 참고
```

안전/보통/주의 개수 통계, 위험 문자 목록(코드포인트·대체 문자), 어디가 문제인지 표시한 미리보기를 함께 보여 줍니다.

### 3. 어느 기기에서나 같은 모습으로

기기마다 기호가 다르게 보이던 문제를 두 갈래로 잡았습니다.

- **글리프 폴백 글꼴** — 기기에 글꼴이 없어 두부(□)로 깨지던 문자를 위해
  `Noto Sans Symbols` / `Symbols 2` / `Math` / `Music`, 이모지는 `Tossface`를 폴백으로 얹었습니다.
  Google Fonts의 `unicode-range` 서브셋이라 실제로 필요한 구간만 내려받습니다.
- **글자 표현 고정(U+FE0E)** — `❤ ☎ ✔ ▶ ⚠` 처럼 기기에 따라 컬러 이모지로 튀는 문자는
  이모지 탭 밖에서 흑백 글자 모양으로 고정해 그립니다.
  **화면에서 본 모습 = 문서에 붙여넣은 모습**이 되도록 맞췄습니다.

### 문서·공문 탭

대한민국 행정업무 운영 규정 기준 공문서 특수문자를 7개 블록으로 정리했습니다.

- **항목 구분 기호** — 규정 순서를 시각적으로 안내 `1. → 가. → 1) → 가) → (1) → (가) → ①`
- **보조 항목 기호** — `□ ○ - · △ ▲ ◇ ◆`
- **괄호 및 인용 부호** — `「」 『』 〈〉 《》 〔〕 【】`
- **문장 부호** — `※ 〃 … ‥ ∥ — ― ′ ″`
- **원문자 · 로마자** — `㉠㉡㉢…` `Ⅰ~Ⅹ` `ⅰ~ⅵ`
- **단위 기호** — `㎠ ㎡ ㎢ ㎥ ㎞ ㎝ ㎖ ℓ ㎏ ℃ ㏊ ㏈ ㏗` 등 32종
- **기타 기호** — `△▲▼` `→←↑↓↔` `㈜ № § © ® ™`

## 기술 스택

- **단일 파일** — `index.html` 하나로 완결 (별도 서버·빌드 불필요)
- **Vanilla JS** — 프레임워크·번들러 없음
- **자체 CSS** — CSS 변수 기반 디자인 토큰, KRDS 팔레트 + 치수쌤 파스텔 확장, 다크 모드
- **Pretendard GOV** — 공공서체
- **Material Icons Outlined** — `font-display: block` + 리가처 실측 감지로, 글꼴이 늦거나 못 뜰 때도
  `search_off` 같은 원문이 새지 않습니다
- **localStorage** — 즐겨찾기·최근 복사·설정 저장 (v1 기록 자동 이어받기)
- **Service Worker** — 앱 셸 네트워크 우선, 글꼴 CDN stale-while-revalidate

## 데이터 구조

문자 데이터는 `[문자, 이름, 분류]` 배열로 관리합니다.

```js
var D = [
  ['★', '검은별', 'pop'],
  ['→', '오른쪽화살표', 'arrow'],
  // ...
];
```

이모지·도형·문서 탭은 각각 `EMOJI_SECTIONS` · `SHAPE_SECTIONS` · `DOC_SECTIONS` 로
분류 섹션을 정의하고, 로드 시 `mergeSections()`가 `D`에 병합해 전체 탭·검색에도 노출합니다.

```js
mergeSections(EMOJI_SECTIONS, 'emoji');
mergeSections(SHAPE_SECTIONS, 'shape');
mergeSections(DOC_SECTIONS,   'doc');
```

호환 등급은 `gradeOf(문자)`가 코드포인트를 보고 판정하며,
안전 구간은 `SAFE_RANGES` · `SAFE_EXTRA`, 위험 문자는 `EMOJI_PRESENTATION`,
대체 문자는 `SAFE_ALT`에 정의되어 있습니다.

```js
gradeOf('★')  // { grade: 'A', why: 'KS X 1001 특수문자 영역이거나…' }
gradeOf('⭐')  // { grade: 'C', why: '기본 표시가 컬러 이모지라…' }
altOf('⭐')    // '★'
```
